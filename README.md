# iPhone Screen

Бесплатная трансляция экрана iPhone и iPad на Windows 10/11 через AirPlay — для стримов, презентаций и повседневного использования.

**[Сайт приложения и скачивание](https://phone-screen.xyz/)**

[Актуальная версия 1.2.0](https://github.com/mr-insider/iphone-screen-releases/releases/latest) · [Скачать установщик](https://github.com/mr-insider/iphone-screen-releases/releases/download/v1.2.0/iPhoneScreen-Setup-1.2.0.exe)

В версии 1.2.0 исправлено зависание и падение при просмотре видео, повороте экрана и изменении размера окна. Управление iPhone с компьютера и встроенные сообщения удалены; приложение предназначено для трансляции экрана.

Windows 11 x64. Для Windows 10 22H2 x64 (19045) добавлена предварительная совместимость: проверка на реальном компьютере с Windows 10 ещё не выполнена.

Здесь размещены установщики, описания выпусков, лицензии и исходники открытых компонентов. Для запуска нужен только установщик из актуального выпуска. [Архив открытых компонентов](https://github.com/mr-insider/iphone-screen-releases/releases/download/v1.2.0/iPhoneScreen-OpenSource-1.2.0.zip) содержит необходимые лицензии и исходники; [SHA256SUMS.txt](https://github.com/mr-insider/iphone-screen-releases/releases/download/v1.2.0/SHA256SUMS.txt) — контрольные суммы файлов.
