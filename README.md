**[Сайт приложения и скачивание](https://phone-screen.xyz/)**

[Актуальная версия](https://github.com/mr-insider/iphone-screen-releases/releases/latest)

Здесь размещены установщики, описания выпусков, лицензии и исходники открытых компонентов. Для запуска нужен установщик Windows 11 x64 из актуального выпуска.
